# 生活圈结果复用与缓存有效期

日期：2026-10-13。用户反馈生活圈未触发缓存。

## 排查及修正

只读检查最近100条产品账本记录发现，算路已有22条命中缓存、70条实时记录，设施查询8条实时记录；不能据此称所有生活圈请求未缓存，也不能把首次查询算作失败。原始缓存以完整参数键及6小时有效期工作。此前分类/同义词变更、新半径或新采样坐标会形成新请求；界面每次分析又清空证据并逐类发送HTTP请求，缺少页面结果复用及明确提示。

现在生活圈按地点、时间、圈边界、采样坐标、服务ID及同义词/排除词建立内存结果缓存。只有完成类别保存，未知或失败继续重试。同圈再次分析复用已有分类结果；添加服务只查询新增类别。不同地点、时间、圈或词典不会交叉复用。返回相同范围后，仍可命中未过期的旧结果。

原始API有效期不变。服务端POI及有向矩阵响应新增 `expiresAt`；缓存命中返回原始到期时间，矩阵索引复用取相关原始响应中最早到期时间，不从本次命中时间续期。POI响应提供明确 `cacheHit`，矩阵原有命中字段保留。

前端缓存到期取POI、所有实际测量矩阵的最早到期时间，并限制本次内存驻留最多10分钟/50个类别结果；缺失到期元数据不保存。读取及写入深复制，模拟新增不能污染保存的真实基线。过期后通过后端原始缓存继续校验，不延长其6小时TTL，不读取过期结果冒充实时。

页面显示「已复用N项结果」，完整报告记录类别复用状态；这可能是页面内存复用或完整类别的后端POI/矩阵命中。部分接口命中不宣称整个类别已复用。刷新会清除页面内存缓存，服务端持久缓存仍有效；没有离线能力承诺。选址候选测量仍单独依赖原始OD缓存，不宣称所有HTTP请求永远为零。
