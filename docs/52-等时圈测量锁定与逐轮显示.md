# 等时圈测量锁定与逐轮显示（2026-10-15）

按用户要求，生活圈及其时间分层测量期间统一锁定业务交互。锁定状态覆盖初始请求、后台基础圈、后续加密与时间分层；正常完成、服务失败或轮询失败退出后解除。

- 搜索、收藏选择、时间参数、设施操作、报告、重置通过disabled fieldset及inert锁定；主导航禁用，路由守卫还拦截程序跳转和浏览器站内返回。
- 地图POI、选点、路线及定位入口暂停，正在等待的定位回调失效；地图平移、缩放、图例、面板收起仍可使用，便于观察边界。
- 圈请求入口拒绝重复启动；同次请求开始清除旧实测圈，先显示明确区分的预估虚线。失败后不由设施分析自动再启动一次圈，保留错误供手动重试。
- 自适应核心在每轮中点检测、括界和二分加密之前发布独立的完整实测边界副本。先显示16向基础圈，再显示已成功加密的边界，继续下一轮；后台终态发布最终结果。缺测方向不补造半径。

前端继续从同一任务状态轮询，地图使用每次返回的实测radiiM直接重建，不改比例尺、不等待全部细化完成才显示。快于轮询间隔的缓存阶段可能合并为最新边界，本次没有为强制播放中间帧插入人工等待。

- 24项后端算法/任务测试通过，新增断言基础圈先发布、发布的轮廓及警告不受后续原地加密修改。
