# CI失败修复与浏览器回归

2026-10-16，修复GitHub首次完整项目同步后暴露的问题。本次只更新源码与自动检查，不部署服务器，不消耗百度或大模型额度，不改动本机原始数据库。

## 实际缺陷

- 网格任务过早显示完成：核心算法的最后一次进度回调发生在派生缓存及任务索引写入之前，立即读取沿途缓存时可能少一个中心。现在写入两者后才发布完成。新增两项确定性测试，分别阻塞结果写入与任务索引写入，验证期间任务仍在运行、完成后缓存可读。
- 行程入口丢失：旧安排条删除后，成功规划的详情入口一起消失。现在途经点下提供“查看行程”，继续使用原有详情和预演，不恢复旧安排条。
- 收藏地图选点：补上添加收藏中的地图选点入口，并使用独立收藏目标。确认后保存地点并返回收藏，取消后返回添加页，不误改起终点；同时补回收藏地点删除按钮。
- 重选同一中心：选点会清除旧结果，但仅监听坐标字符串无法触发同坐标重新生成。现在以明确的选点序号触发，接口返回的坐标转换不会触发新一轮计算，缓存仍可复用。
- 长地址：搜索入口中的已选中心允许换行，保留地点名称的文字重点，避免手机端截断。

## 浏览器测试调整

按当前操作更新测试：选中心自动生成5/10/15分钟层，后续分析固定15分钟；收藏统一入口；途经点下查看行程；删除途经点代替已移除的重新开始。保留缓存请求计数、未知类别、评分、报告、地图联动、异常恢复、路线反向、拖动排序、刷新持久化和键盘焦点检查。

绘图检查针对当前圆角后的边界：开放边界端点不移动，中间点保持在实测边界包围范围内，不再要求等于旧原始折线数组。算法分类与分析边界未因此改动。

CI固定两个浏览器工作进程，禁止误留仅运行单项测试的标记，使用独立启动的前端服务；失败保留浏览器追踪文件，不通过自动重试掩盖失败。
