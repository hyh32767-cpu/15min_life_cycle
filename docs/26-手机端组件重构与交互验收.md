# 手机端组件重构与交互验收

本轮依照最新要求暂停功能扩展，保留原配色，采用地图、可拖动底部面板和固定底部导航的手机布局。实际修改目录为 `/Users/heyh/projects/15min_life_cycle/web`，当前 Codex 工作树是早期算法版本，不包含现行 Vue 应用。

## 组件与体验修复

- 通勤候选列表和地点详情拆成独立组件，复用展示格式，修正零分钟绕行文案。
- 底部面板支持点击和上下拖动；切页恢复收起状态。适配动态视口、安全区和至少 44px 的常用触控目标。
- 修复类别区横向裁切；安排弹窗支持背景点击、Escape、Tab 焦点循环、关闭后恢复焦点与滚动。
- 固定地点和灵活类别均打开安排弹窗；地图选点临时关闭弹窗，确认后恢复原表单。
- 空停留时间明确报错，不再被转换为零。预计到家时间跟随当前选择的方案。
- 地图先调整范围再添加覆盖物，减少重复标签；尺寸或中心变化后重新适配范围。按页面隔离通勤地点、任务、等时圈与社区覆盖标记。
- 社区地址搜索补传城市。搜索选中后隐藏候选列表。手机端恢复历史案例入口。
- 删除页面中的 API/SDK、JSON、内部来源枚举、网格编号、原始警告码等开发说明；保留测量不完整、未知营业时间和新增设施模拟的必要说明。

## 验证证据

命令：`npm run lint && npm run typecheck && npm test && npm run build && npm run test:e2e`。

结果：lint 无错误或警告；类型检查与构建通过；14 个单测文件、58 项单测通过；8 项 Chromium 端到端测试通过。新增手机回归覆盖面板高度与切页、弹窗焦点与退出，以及停留时间请求值。

使用 Codex Computer Use 操作 Chrome 原生窗口，设备视口 390×752、375×752，并检查桌面。实际连接本地 live API 与百度地图，未用静态地图替代视觉检查。

## 验收边界

这是前端组件与手机交互验收记录，不等于赛题整体终验。未授权传送设备精确位置，因此没有实际提交浏览器定位；没有声称覆盖所有浏览器、全部路线、所有异常事件组合。百度实时测量可能部分失败，界面保留真实失败状态。历史案例目前只显示研究摘要，地图不绘制历史边界。

原始算法和赛题开源交付检查仍按原 TODO 单独验收；本轮不将它们标为完成。
