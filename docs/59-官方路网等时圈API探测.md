# 官方路网等时圈API探测

日期：2026-10-16。用户要求测试真实路网等时圈，并询问是否有API。

## 接口与现有实现

百度官方等时圈文档：https://lbsyun.baidu.com/docs/webapi?title=isochrone/guide/isochronicLines/base 。接口GET `/logistics_truck/v1/isochrone`，步行可用profile=foot_fastest，timeLimit单位秒，point为经度、纬度，支持输入和输出BD09。响应result.path为范围多边形坐标；文档没有承诺返回完整道路图或每条可达道路几何。

项目现有POST `/api/isochrones`不是该官方接口的封装：它用百度真实有向步行耗时矩阵做自适应射线探测，射线多边形用于判定，Delaunay线性时间场生成显示等值线。后者不是完整路网边界，不能把真实耗时等同于完整路网几何。

## 一次真实调用

从腾讯云服务器读取既有服务端凭据进行签名调用，没有输出凭据。参数使用官方公开示例point=116.307878,40.057027、foot_fastest、timeLimit=900，输入/输出均bd09ll；没有读取设备位置。

| 项目 | 结果 |
| --- | --- |
| 网络尝试 | 1，无重试 |
| HTTP状态 | 200 |
| 百度业务状态 | 240 |
| message | APP 服务被禁用 |
| 响应耗时 | 0.634秒 |
| 多边形 | 未返回 |

因此当前服务器AK不能调用该能力。0.634秒仅为本次拒绝响应耗时，不是等时圈生成速度。需要在对应应用中检查等时圈服务权限及开通条件；未登录控制台，无法确认具体禁用原因或收费条件。现有路线/矩阵服务是否可用不能据此接口的业务拒绝推断。

本轮没有改代码、替换线上算法或新增采样整圈请求。官方服务可用后才能测试边界形状、5/10/15层实际速度及与项目分析的几何一致性。
