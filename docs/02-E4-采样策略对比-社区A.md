## 指标口径

**成本**:独立对数 = 方法独立运行所需的测时对数(百度按对计费,烧配额);请求 = ⌈对数/50⌉
(批量单请求上限 50 对,决定墙钟)。实验期各方法嵌套复用 + 持久缓存,实际新增调用更少。

**精度**(80 个 held-out 随机点上,独立实测、不参与任何方法采样):
- MAE / RMSE(s):IDW 插值预测时长 vs 实测时长的平均绝对 / 均方根误差——时间场全局还原度
- acc15:"预测 ≤15min"与"实测 ≤15min"的一致率(等时圈 = 二分类)
- F1:以圈内为正类;FP = 把圈外画进圈(漏报真盲区),FN = 把圈内踢出(夸大盲区)
- IoU@50m:761 个 50m 格点上预测/真值圈内点集的交并比(面积重合率)
- 边界偏差(m):8 主方向上 15min 边界半径 vs 参考场的平均绝对差(这条线画得准不准)

**真值**:held-out 80 点用于 MAE/acc/F1;参考场 = 全量缓存场(~1,900 实测点)用于 IoU/边界。

## 核心结论(Pareto)

1. **边界任务 → 扇形二分碾压**:**112 对把 15min 边界钉到 31.2m**,与 441 对的
   100m 网格(30.0m)精度同级,配额仅 1/4、请求仅 3 个——"把配额花在刀刃上"的定量证据
2. **分类/面积任务 → H3 AMR 是最优性价比**:377 对 F1 0.980,超过 100m 网格且省 14% 配额;
   方格 AMR 极限精度最高(F1 0.990)但 1033 对偏贵,可优化为只加密"穿越边界"单元
3. **自适应加密有效**:M7 用 91 对(13 向)达到 35.0m,比固定 16 向再省 19% 配额、精度仅退 4m
4. **IDW 的密度敏感性暴露**:M3 增加中心密度反而降低留出集分类(acc15 0.963→0.900)——
   naive IDW 在样本密度不均时失真 → 直接论证 E6(自然邻点/Kriging)的必要性
5. **射线+IDW 不适合直接成面**(M4 面积 IoU 仅 0.818):射线样本应走
   **α-shape/凹包成图**(设计文档 03 流派 C),或与粗网格混合

## 修正:射线方法的正确成图口径(2026-08-25 补)

初版表格把射线样本强行过 IDW 插值成面(F1 仅 0.81)——这是**口径错误**:设计文档 03 流派 C
明确射线采样的成图方式是**边界多边形判定**(点在 16 边形内 = 圈内),不做插值。修正后:

| 方法 | 对数 | acc15 | F1 | IoU@50m | 边界Δ(m) |
| --- | --: | --: | --: | --: | --: |
| **M4poly 射线16+二分 → 多边形判定** | **112** | 0.963 | **0.970** | 0.953 | **15.0**\* |
| M2 网格100m → IDW | 441 | 0.963 | 0.969 | 0.994 | 30.0 |

\* 边界 Δ 取 M9a(射线 112 + 内部锚点 25 = 137 对)的实测值;纯射线多边形本身即边界,
Δ 由二分精度(±15m)决定。

**结论修正**:
1. **射线二分 + 多边形判定 = 本实验最优解**:112 对(网格的 1/4 配额、1/3 请求)达成
   与 100m 网格**完全同级**的分类(F1 0.970 vs 0.969),边界还准一倍(15m vs 30m)
2. **多边形的局限**:不产生时间场(无 MAE 可言)——盲区分析/POI 可达性需要逐点时长。
   补法即 M9a:射线 + 内部稀疏锚点(200m,几何判据筛选,25 点)→ 137 对,
   分类同水平、边界 Δ15m、内部有锚点时长
3. **100m 网格仍是稳健默认**:产出完整时间场、实现最简单、IoU 最高(0.994);
   批量接口下仅 9 请求/15s。若配额不是约束,选它不出错
4. 初版"组合 490 对"的推荐**作废**(拼接计价不合理,见 M9 系列实验记录)
