# 产品文案与信息层级整改

2026-10-13。按用户要求扫描通勤、安排/预演、社区、步行范围、时间空档、地点/路径库、地图选点、历史案例及使用记录的界面文字。保持蓝紫风格，地点与结果优先，辅助操作次要。源码公开仍最后处理。

## 文案与布局

- “基线到达终点”改为“原计划到达”，“重排剩余行程”改为“更新后续路线”。“虚拟时钟/当前虚拟时间”改为“行程预演/预演时间”，开始按钮明确为“预演行程”，不暗示真实定位跟踪。
- “整体规划”改为“规划行程”；任务计数改地点计数，操作改“加入安排/完成”，保留必去地点跳过确认。失败原因保留具体冲突，但不展示内部原因码、任务 ID 或组合失败次数。
- 社区地点卡移除三段重复选点说明，移除重复标题和搜索/定位/点选标签。当前地点为 18px、700 字重、深色并完整换行；搜索行 13px，地图/定位/清除为 12px 次要文字操作，保留 44px 点击高度。修复旧 `.search` 样式不匹配新 `.place-search` 的布局问题。四档时间等宽同一行，在桌面也保留 44px 高度。
- 社区采样与有限检索范围改为简短说明；保留每类最多五家、未覆盖不代表现实缺少设施、模拟新增不代表实际存在等必要边界。原始报告标识及算法版本仍在报告追踪中保留。
- 地图图例只显示当前实际存在的图层，原路线/行程路线/步行范围采用用户用语。长文字标签限制宽度并省略显示，完整名称仍在地点卡及无障碍名称中保留；地图版权保留。
- 正常连接成功徽标隐藏，服务异常仍提示。“调用账本/全局复位”改为“使用记录/重新开始”。使用记录继续区分真实查询和有效缓存复用。
- 空档页移除公式和重复方向说明，结果改“来得及/来不及”，两项输入改双列并将单位固定在输入旁，避免手机端单位换行。
- 行程预演此前错误区域绑定了规划错误，现独立显示执行错误，时间格式错误、更新失败可直接看到；保留模拟事件及其真实计算链。
