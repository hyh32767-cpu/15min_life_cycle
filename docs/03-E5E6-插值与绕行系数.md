### 三级结论修正链(E4 → E10 → E6,答辩叙事主线)

1. E4 初判:"射线+IDW 不适合成面"(F1 0.808)→ E10 修正:射线配**多边形判定**分类同级
2. **E6 再修正:射线配 Delaunay 线性插值,时间场也同级**——
   **112 对射线轨迹 + Delaunay:MAE 120.5s / F1 0.970 ≈ 441 对网格 IDW(119.5 / 0.969)**
   → 射线方案从"边界专精"升级为**全能替代**,配额仍为 1/4
3. E4 的 IDW 密度敏感悖论(M3 加密反而掉分)根因确认:**IDW 的 p=2 全局权重**;
   p=3(更局部)或 Delaunay(仅相邻点插值,天然局部)即可解决

### 选型建议

- 时间场任务:优先 **Delaunay 线性**(scipy griddata 现成);IDW 需 p=3
- 边界任务:多边形判定(与插值无关)
- 自然邻点(Sibson)未测(scipy 无现成实现),Delaunay 线性已够用

### 结论

1. **城市间差异显著(1.21–1.52)**:笔记经验值"1.2–1.4"整体偏乐观;降级兜底必须**按城标定**,
   固定 1.3 在北京B 会系统性低估 17%
2. **分区中位(方位×距离带)在全部六城胜出**——设计文档 09.3 的"反推标定当地系数"升级为
   "反推标定当地分区系数表"
3. **兜底精度天花板明确**:MAE 53–170s、acc15 0.71–0.87——降级链可用但仅是兜底;
   P95 尾部(过江 3.16、铁路 5.0)证明**跨障点没有任何系数能救,必须真实测时**
4. 中位步速六城一致 ≈4.2 km/h(比 E2 的 3.9 略高,E2 含 100m 短距点)
