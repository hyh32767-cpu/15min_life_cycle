# 生活圈设施地图与文字精简

日期：2026-10-13。承接用户两项要求：选择设施类别时在地图加入 POI 图标及信息；删除分类卡下方截图中的冗余说明及已覆盖采样点。

## 当前行为

- 分类覆盖选择与地图同步：只展示当前类别实际参评的设施（最多五家），使用对应服务图标。医疗、药店、菜市场、早餐、养老、托育等29项均有图标映射，未查询或未确认的设施不凭空生成。
- 点设施图标查看名称、地址、类别和来源。无地址显示暂未提供；不自动请求详情或步行路线。明确点「从圈中心步行到这里」才使用已有真实路线服务；从圈中心的路线与采样点覆盖口径分开。
- 生活圈设施图标点击不会误触发修改圈中心或地图选点。主动进入选点模式时，仍可选中设施坐标并走已有确认流程。
- 更换类别/时间/中心、重算或清空结果同步移除旧设施和详情。旧类别标记事件使用服务ID及地点身份校验，不按过时数组位置回填。
- 地图不再绘制已覆盖采样点，只保留未覆盖点和设施图标；统计、计算及报告中的完整采样数据保留。设施路线预览时生活圈类别面板不隐藏，可以继续切换类别。
- 删除截图区域的「已选择…最多五家」「返回社区中心」、重复有限检索说明和分类错误汇总长句。类型或测量未知的分类卡使用「待查明」，不再称「不可用」。必要范围边界保留于覆盖详情和报告中。
- JSON报告的地图部分补充当前设施及可见标记类型，避免误以为所有绿色采样点仍绘制。

## 验证

1项地点身份/失效单测、7项社区覆盖/打印/省额度回归，以及7项设施地图/途经点/手机面板交互通过。新地图用例覆盖：图标显隐、名称地址、点图标零算路、显式路线一次、类别切换清理、已覆盖点不显示、未覆盖点保留、时间改变清理、手机无横向溢出。

Lint、类型与生产构建通过，业务测试均使用构造数据，本轮没有真实设施或算路查询。之前记录的原生Computer Use窗口定位阻塞未恢复，不将自动地图交互声明为真实SDK原生复验。
