# 盲区判定范围与自适应区域检查

2026-10-13。用户指出只采样九格不足以支撑区域盲区判断，本轮纠正判定及地图表达。本文替代 docs/36 中“步行采样结果铺满500米格”的展示约定；历史证据不据此升级为当前区域精度验收。

## 确认的问题

1. 五类步行覆盖确实只有九个固定中心点、每类最多五家参评设施，不能代表社区全部地点或现实设施全量。此前把点结果填满整格，空间结论超出了测量证据。
2. 原1公里检查也只判定九个格中心，没有确认整格；检索1.8公里能覆盖原格中心的1公里邻域，但不能覆盖1.5×1.5公里研究方形中每个位置向外延伸1公里的邻域，边缘可能漏设施。
3. 覆盖后端将缺测/失败忽略后计入盲区，前端虽有防护，直接调用仍存在误判。

## 修改

五类步行结果明确标为“9点快检”。`createCommunitySamples`只为这一快检生成固定点；地图仅标测过的点，未知结果不生成点位覆盖判断，不再填整格。界面统计改“点/未覆盖采样点”，综合分仍限于有限候选和九点测量，不称完整社区评分。更密集的真实路网区域评估仍未实现，本轮没有为九点结果虚构插值区域。

独立1公里检查使用中心周边1.5×1.5公里研究方形，36个250米格起步。查三类设施时检索半径/缓冲扩至2.2公里，包含研究范围外仍可服务边缘的设施。保持每类最多五页、最多100条的上限；分页截断或错误必须显式未知，未扩大成不限额检索。

整格使用保守距离上下界：对格中心到最近设施的距离d、任意格内位置到中心的上界r，`d+r<=1000`可证明整格该类覆盖；仅当该类检索完整且`d-r>1000`才证明整格该类缺失。r使用经线/纬线路径长度上界，不用格中心是否可达代替整格结论。

若边界格既不能证明全覆盖也不能证明缺失，则四分，250→125→62.5米；最细仍不确定保留“服务边界待查明”。任意一类可证明整格缺失即可标灰；检索未完整仍允许已有设施证明覆盖，但不能证明缺失。三类均证明覆盖才标绿。灰色面积按叶格大小求和，显示近似面积，不用不同大小的格数量推算覆盖比例。研究范围未扩到城市或行政社区边界。

此计算复用一轮POI数据，细分不产生矩阵/路线请求；更大检索半径可能增加实际返回量和分页需求，但上限不变。1公里依旧是地理距离，不能替代15分钟真实路网可达性。

后端只有有效`ok`测时或明确`no_route`才算已知边；未覆盖点若仍缺任何必要设施测量，则422 `INCOMPLETE_COVERAGE`，不输出假盲区。若已有其他设施实测可达，则仍允许OR提前结束。模拟新增同样检查必要测量，不能把缺测当成无改善。API响应字段兼容，语义收紧，客户端给出可理解提示。已重启本地服务使修正生效。

- 覆盖/执行相关后端契约10项通过：失败缺测422、其他已知可达设施允许提前结束、明确不可达、真实模拟前后差量。
