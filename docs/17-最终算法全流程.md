## S2 等时圈引擎(核心)

### 第一步:8 向起步二分(tol50)

```
8 个均匀方位(0°/45°/.../315°)
每向在 [200, 1400]m 区间二分,tol=50m
成本:8 向 × ~8 探针 = ~64 对
```

**附带产品**(零额外调用):
- `aniso8 = max(r)/min(r)` → 地形自信号(69%,误判代价≈0)
- 弦差计数(|Δr|>200m 的弦数) → 复杂度信号
- **这就是生产环境的地形感知**——不需要前置模块

### 第二步:自适应加密链(统一触发器 v7)

对当前多边形的每条弦(相邻两向),按序检查四个触发器:

| # | 触发器 | 条件 | 检测目标 | 验证 |
|---|---|---|---|---|
| ① | 弦违规 | 扇区内实测超时点深入多边形 ≥40m | 外凸过头(幻影) | E10 防线1 |
| ② | 长弦 | 端点直线距离 >200m | 稀疏欠采样(直切) | 遵义复盘 |
| ③ | 场线偏差 | 弦中点方位与实测边界差 >60m(双向) | 低估或高估 | v3 复盘 |
| ④ | **梯度** | dz/arc > 12 m/° | 陡弦(针/峡谷前兆) | S5G 统一 |

任一触发 → 在弦中点方位插入射线(半径取场阶梯实测值,tol25)。

**密度保护**:
- 物理下限:弦长 ≥150m(用户指示,密度上限 ~32 向)
- 密区模式(k≥40):只响应 ④梯度 和 ③"漏画"(L>cur),防止密度爆炸
- 间隔带/复通带扇区:wedge-skip(由楔形层负责,射线层不触发)——P1 修复
- 收敛保证:梯度制插入中点后弧减半→梯度减半→2-3 轮收敛(S5G 实证)

**插入值来源**:场阶梯首穿越(ladder_r)——与 50m 重建场同源、任意方位可取、双向

### 第三步:mid 探针清零(防线 1)

```
对每条最终弦:在 0.97 × r_at(mid) 处实测
超时 → 该弦外凸(幻影边界) → 插向重二分 → 重复
收敛判据 = 违规清零(不是 F1——"F1 会说谎")
```

### 第四步:多 15min 点检测(复通带 + 间隔楔)

对每条射线的时间剖面(阶梯):

| 模式 | 含义 | 表示法 |
|---|---|---|
| OK → X → OK → X | 圈内间隔带(障碍楔) | `interior_gaps` → 深红斜线楔形 |
| 主边界 → X(隔离带) → OK → X | 复通带(桥廊) | `pockets = {r, gap:[g0,g1], outer}` → 青绿楔形 |

**提取规则**(零 API,从缓存阶梯读):
- 间隔带:X 带严格夹在两段 OK 之间、宽 ≥20m
- 复通带:主边界后有"超时带夹层"再可达(需实测精测 g0/g1/outer)

### 第五步:边界三层表示

| 层 | 内容 | 用途 |
|---|---|---|
| **主多边形** | 射线半径集合(k=16-124) | 分类/面积/快速判断 |
| **重建场** | 全样本 Delaunay → 50m 格 + 弦约束(超该向边界+80m 置 NaN) | 精确等值线/可视化/空间查询 |
| **复通带+间隔楔** | pocket + interior_gaps | 桥廊/障碍的显式分层 |

**分类口径**:R2并+复通带−间隔带(二十六社区平均 IoU 0.924-0.934)
