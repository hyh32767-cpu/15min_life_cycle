## 一、后端功能(BE-1 ~ BE-9)

### BE-1 分析任务 API
| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/analysis` | POST | 创建分析。入参 `{addr?}` 或 `{lng,lat}`;返回 `{analysisId, status}` |
| `/api/analysis/{id}` | GET | 轮询结果;含 `status/state/progress/result` |
| `/api/analysis/{id}/events` | SSE | 实时进度推送(阶段、当前对数、缓存命中数)|
| `/api/analysis/{id}/ledger` | GET | 本次账本:`{requests, pairs, cacheHits, byStage[]}` |
| `/api/analysis/{id}/report.md` | GET | 下载体检报告(md)|

**任务状态机**:`QUEUED → RUNNING{geocode|isochrone|poi|scoring|prescription|report} → DONE | DEGRADED | FAILED`
- `DEGRADED`:配额/限流触发降级链后的**成功**态,响应带 `degraded: true` 与降级层级,前端显示横幅
- 进度事件 payload:`{stage, donePairs, totalEstimate, cacheHitRatio}`

### BE-3 引擎服务层(内部模块,只列职责)
`GeocodeService / IsochroneEngine(对应F2-F3) / PoiService(F4) /
DiagnoseService(F5) / PrescriptionService(F6) / ReportService(F7)`
——全部由 `pipeline.py` 六步直译;对上层只暴露同步/异步两种调用。

### BE-4 三级缓存与账本
- 缓存表:`geocodes`(地址→中心)、`poi_search`(关键词+页)、`walk_times`(origin+dest→时长/距离)
- **缓存命中不产生任何外部调用**;`GET /api/analysis/{id}` 的同地址重跑必须返回 `ledger.pairs==0`
- 账本表 `calls`(EID、ts、kind、n_pairs、status)只追加不可改;提供按日/按 EID 聚合查询端点 `/api/ledger/summary`

### BE-5 配额与限流中间件
- 预算守卫:每任务 `maxPairs`(默认 300)、每日总额;触顶 → 任务转 `DEGRADED`,**不产生占位假数据**
- 令牌桶限流(默认 10 QPS);401/302 指数退避(15/30/60s),三次后进入降级
- 降级链执行顺序 L0→L3 固定,当前层级写入结果 `degradedLevel`

### BE-6 地图静态数据 API
| 端点 | 说明 |
|---|---|
| `/api/cities` | 十六城档案(名称/类型/指标/产物文件名),供"案例库"页 |
| `/api/cities/{slug}/artifacts/{file}` | 返回该城 png/json 产物(演示模式零 API 出图)|
| `/api/tiles` 不做 | 底图由前端直接接 OSM/百度 JS API |

### BE-7 多阈值切换
`GET /api/analysis/{id}/isochrone?min=5|10|20` —— 优先复用仍有效的真实响应缓存；缓存缺失时重新请求 API，不生成人工结果。

### BE-8 安全与运维
- AK 仅存后端 `.env`;响应永不回传密钥;CORS 白名单;结构化日志(请求级 traceId)
- 健康检查 `/healthz`(含配额余量、缓存行数);Docker Compose:`web`+`api`+`data 卷(缓存/台账)`

### BE-9 测试(零调用 CI)
- 契约测试:schema 校验 + 示例响应对拍
- **缓存命中测试**:对已有真实 API 响应跑分析，断言重复请求不产生新的上游调用；CI 使用 mock adapter 验证契约，不构造人工空间事实
- 降级演练:mock 302/401,断言 `DEGRADED` 且无假数据

## 二、前端功能(FE-1 ~ FE-8,Vue3)

### FE-1 地图首页 `/`
- 搜索框(地址联想)、地图点击选点、Marker 可拖拽;选中后显示"📍当前体检中心 + 反地理名称"
- **开始体检**按钮(显示预计消耗:"首跑约 200-300 对;本站已缓存社区 0 对")
- 案例库入口(十六城,点开即看成品图与指标,零 API)

### FE-2 分析页 `/analysis/:id`
- 左:地图画布;右:结果面板(可折叠);顶:进度条 + 实时对数/缓存命中(SSE)
- 顶部状态徽标:`完成` / `降级模式 L2(直线估算)` / `失败重试`

### FE-3 图层面板(勾选式,分组)
| 组 | 图层 | 默认 |
|---|---|---|
| 边界 | 主多边形 / 50m 重建场 / 复通带楔 / 圈内间隔楔 | 全开 |
| 证据 | 15min 穿越点X / 射线与探针 / 采样点热力 | X 开 |
| 方法对比 | 自适应16/8起步、均匀基线、网格线、H3、OSMnx参照 | 关 |
| 体检 | 盲区三色 choropleth / POI 气泡(五类分色)| 开 |
| 阈值 | 5/10/15/20min 单选切换 | 15 |

### FE-4 盲区诊断卡(点击盲区弹出)
字段:类型徽标 / 最近设施名 / 直线距离 / 步行距离与时长 / 绕行系数 /
若该盲区叠加复通带或圈内楔 → 追加"结构性障碍"段落(隔离带区间、复通范围)。
按钮:「看处方」滚动到处方卡。

### FE-5 结果面板
- 五类覆盖率进度条 + 综合分大数字
- 盲区列表(按严重度排序,点击地图飞行)
- 处方卡:选址坐标(一键复制)、百度口径覆盖率、与 OSM 初筛对比行
- 报告预览(md 渲染)+ 下载;**账本行**:"本次实际消耗 N 对 / 命中 M 次"

### FE-6 交互细节
- 分析中地图上**实时生长**边界(每阶段推送后追加渲染),对数计数器跳动——演示核心观感
- 同地址重复体检:前端直接读缓存结果并显示"0 次调用 ✓"徽标
- 错误态:限流横幅(倒计时重试)、`DEGRADED` 黄色横幅说明当前降级层级与含义

### FE-7 案例库页 `/cities`
十六城网格卡:缩略图 + 关键指标(IoU/各向异性/对数);点击大图 + 指标详情(BE-6 数据)。

### FE-8 导出与分享
- 报告 md/PDF 下载;地图快照 PNG(含图例);`?id=` 链接复现(结果只读视图)
