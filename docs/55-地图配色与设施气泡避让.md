# 地图配色与设施气泡避让

2026-10-15，继续使用`codex/prototype-ui-circle-visuals`分支，仅修改本地前端；腾讯云不启动、不部署。

## 实现

- `mapTheme.ts`定义暖白陆地、淡青水系、低饱和建筑/绿地和白色道路；保留道路、POI、原生图标点击和地图版权信息，不用CSS滤镜改整张底图。采用百度JSAPI 4.0 `setMapStyle({styleJson, merge:true})`。同步异常保留默认底图，不中断地图初始化。
- 主圈填色透明度0.075，时间分层0.07，预估虚线0.025。分层按外圈到内圈绘制，重建边界增加6px白色衬线和3px彩色主线；几何点、判定多边形及算法没有改变，没有样条平滑或增加采样。
- 生活圈中心改为深色名称气泡；设施气泡显示真实名称和当前类别，选中为蓝色描边，顺路设施可显示已有`extraTravelSeconds`。未取得的步行分钟数、营业信息不补造。
- 屏幕投影后按选中设施、中心、其余地点排序，在上/右/左/下四方向尝试放置，文字之间留8px间隔，并避让其他设施锚点。窄地图最多4个名称、宽地图最多7个，放不下名称的设施仍保留原位图标及原点击身份；只调整Label偏移，不改变坐标。
- 避让可见地图边缘、右侧控件、底部/桌面工作台、设施详情卡、路线详情、加载提示和图层按钮。图层watch在DOM更新后执行；平移/缩放结束重新安排标签，不调用算路或自动缩放。JSAPI容器增加独立堆叠上下文，防止Label穿透盖住浮层。
- 气泡用引线和原位锚点表达实际位置；移除旧中心重复标签。点击中心气泡关闭设施详情并回到圈中心，不重新生成圈。名称/类别HTML转义，键盘和点击仍通过原标记revision/index委托。
- 手写DOM气泡样式统一在`mapVisuals.css`，减少动态效果设置禁用过渡。SDK替身缺少屏幕投影时保留可展示的回退；真实地图按可用投影避让。

官方接口依据：[百度JSAPI 4.0地图样式风格](https://lbs.baidu.com/docs/jsapi?title=jsapi4/guide/map/style)。不更换地图服务，不使用新的控制台样式ID或外部图标依赖。
