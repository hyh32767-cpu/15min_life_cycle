## 算法与实验检查

只读核对的证据：

1. `experiments/results/e0_instrument/e3_concurrency.json`：2/4/8/16 QPS各40次，均成功；docs/01建议生产10 QPS匀速和401冷却15/30/60秒。没有重新压测真实服务。
2. `experiments/results/e0_instrument/e12_route.json`与`e12_route_v3_external.json`：20个场景的8/16向选择实验，记录LOO .85/.90；属于历史样本结果，不能称任意在线地点的精度。
3. `experiments/results/e4_sampling/e50m_summary.json`：历史441点网格的完整记录。当前在线圈内最多25个采样点，不能把历史441点结果显示为本次覆盖或人口覆盖。
4. docs/01已记录104点中10处射线非单调；当前在线v4为有预算的8向批量括界/二分，不能证明任意两射线之间或同射线复通带的全部可达性。docs/19旧在线档的加密/mid/pocket步骤是研究目标，当前实现不宣称已完整移植。

修正：

- 正式地图、圈内设施过滤、盲区采样使用同一个`polygonFromRays`，与后端报告的排序/等距圆柱坐标公式一致。删除前端平滑平均和由单圈缩放多个时间层的工具函数，避免把凹口平滑成可达覆盖。`destAt(0)`保留原点，不再补500m。
- 时间分层仅使用各自完整测得的结果，保留缓存和源expiry，不能把15分钟圈缩放成5/10/20分钟。
- partial/degraded/L2结果不作为实测填色或设施分析边界；加载/缺测提示独立。停止在类别加载中先展示L2估计覆盖百分比。仅完整圈才能产生当前覆盖统计，未知不补0。
- Matrix官方文档说明0可能表示没有计算结果：0/缺字段/错误响应记为未知，不能记为瞬间可达，也不能据此推导无路；明确no-route单列。
- 真实覆盖与新增模拟隔离，地图仅按需显示当前类别未覆盖的实测采样点，不画成整片盲区。

## API出口策略

| 类型 | 处理 |
| --- | --- |
| 有效缓存 | 优先复用原始到期时间；单飞leader二次查缓存，避免并发竞态重复收费 |
| 相同在途请求 | Singleflight复用；等待有45秒上界，失败等待者不重复计实际请求数 |
| 普通请求 | 单进程令牌桶默认10 QPS、burst1、最多4上游并发；并发槽等待2秒、令牌排队最多10秒 |
| 百度401或HTTP429 | 降低速率，当前请求立即返回；同接口共享15/30/60秒冷却，返回Retry-After；不挂着HTTP线程睡眠 |
| 日配额4/302 | 不重试，同接口冷却至北京时间下一日；有效缓存可用，过期缓存不能参与规划/覆盖 |
| AK/IP/SN/服务权限错误 | UPSTREAM_AUTH，停止自动重试，接口冷却5分钟 |
| 参数错误 | UPSTREAM_ARGUMENT/VALIDATION_ERROR，要求修改输入，不自动重试 |
| 网络、超时、上游5xx/内部错误 | 每次重试重新过QPS，最多3次；最终短暂冷却，分别返回NETWORK/TIMEOUT/UNAVAILABLE类型 |
| 非JSON、缺状态或异常结构 | UPSTREAM_RESPONSE，明确失败，不伪造成功或空POI |
| 查询中途部分成功 | 保留已确认设施/矩阵单元；其余未知并标截断，不能生成完整覆盖结论 |

低层产品HTTP关闭隐式网络重试，避免绕过统一QPS；研究调用仍保留原有传输重试。错误正文不透传上游URL、签名或密钥。FastAPI返回统一error结构，包含code/retryable/retryAfterSeconds；前端ApiError保留元数据，45秒请求超时，不无限自动重试。

限流/单飞/冷却当前为单进程共享。当前部署为单uvicorn进程；如将来开多worker或多服务器，必须增加共享的配额协调，不能将本方案宣称为跨进程全局限流。

官方依据：[状态码](https://lbsyun.baidu.com/faq/api?title=webapi%2Fappendix)、[步行矩阵返回值](https://lbsyun.baidu.com/docs/webapi?title=routematrix%2Froutchtout-walk)、[矩阵50对上限](https://lbsyun.baidu.com/docs/webapi?title=routematrix%2Froutchtout)。
