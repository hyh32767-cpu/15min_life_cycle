# 地图侧边定位按钮

日期：2026-10-13。用户要求地图侧边新增定位按钮，已部署至腾讯云新版本 `/opt/shunshou/releases/20261013-location/shunshou`。

## 行为

- 右侧地图控制栏新增「定位到当前位置」，有44px触控入口、加载与禁用状态。
- 点击后申请浏览器定位；GPS坐标使用百度JSAPI官方Convertor从WGS84转BD09后移动地图，保留当前比例尺，并显示当前位置标记。[百度JSAPI4坐标说明](https://lbs.baidu.com/docs/jsapi?title=jsapi4%2Fguide%2Fconcept%2Fcoord)
- 地图定位只移动视图，业务起点/终点/生活圈中心仍通过已有确认流程选择。不自动测圈、重算路线、查询POI或逆地理编码；当前位置标记在主动选点流程中可供确认。
- 拒绝授权、不支持定位、定位超时、转换失败/超时均有可操作提示；跨页与卸载丢弃迟到响应。
- 首次部署为HTTP，安全上下文false，点击只提示需要HTTPS。后续docs/45已完成HTTPS及公网/手机尺寸浏览器验收，安全上下文true，已解除此限制；未宣称读取真实设备位置成功。
