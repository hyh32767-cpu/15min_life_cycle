## 最终算法总流程(一页纸 v2,2026-08-31;含加密链/降级链/成本)

```text
━━ S0 免费预判(0 对)━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  起步向数路由(设计中 E12):OSM 各向异性/河网密度/规模 → 8 或 16 起步
  邻近点缓存(设计中 E11):附近源点的既有测值直接复用(ΔT(d) 包络内)

━━ S1-S2 定位与起步 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  geocode 定中心(1 次;geocodes.json 缓存→二跑 0)
  8 向二分 tol50(轨迹前缀性 ⇒ 任意 tol 重放零成本)

━━ S3 加密链(全部证据驱动:候选筛查 0 对,命中才付费)━━━━━
  ① 弦规则   扇区内实测超时点落入当前多边形(违规)或 θ≥30° → 弦中点插向
  ② mid 探针 每弦中点 0.97r 实测(防线1):超时→插向;违规清零或预算尽才停
  ③ ρ 热弦   弦两端实际/直线时长比>τ(防线2):无条件插向(重庆两弦修正 200m+)
  ④ 弦差再平衡 |Δr|>150m 的弦无条件插向(治"针状"渲染,义乌案例)
  ⑤ 小角度弦验证(S5b,防线3):arc≤22.5°且(Δr>80或arc≤11.25°)→在"边中点"
     实测:超时=凹 / 1.06 外扩可达=凸 → 插向 tol25(南昌 +3.3pt IoU/约80对)
  ⑥ 复通带   阶梯含"超时带夹层"的射线 → pocket={r,gap:[g0,g1],outer}
     (一根射线上多个 15min 点,十五城共 6 条,全为江河桥廊)

━━ S4-S6 终审与表示 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  孤岛抽检 K 点(防线3b);收敛判据 = 弦/mid 违规数(F1 会说谎)
  边界三层:射线多边形 + 重建场(Delaunay+弦约束,50m 分辨率)+ 复通带楔形
  分类口径:R2并+复通带(十五城平均 IoU 0.933)

━━ 降级链(任何一层失效即落入下一层,绝不中断)━━━━━━━━━━
  L0 同社区重跑:全缓存命中,0 调用(POI 关键词/geocode/探针三级缓存,docs/12)
  L1 限流/配额尽(302):优雅降级——跳过新探针、不写假半径,既有场继续出图(南昌实证)
  L2 无测时数据:直线距离 × 城市绕行系数 ρ(十五城中位 1.29-1.98)/ 4.2km/h
  L3 无 OSM 路网:去掉底图与 OSMnx 参照层,其余图层照常(五小城实证)

━━ 平均花费(二十社区全台账实测,5907 次/22032 对)━━━━━━━━
  等时圈阶梯(8起步+加密 与 16向均匀几乎相同,19/20 城 0% 差)136-343 对/城;
    长沙类"凹口与网格错位"城 8 向需多轮返工(-152%)→ 省额度靠 E12 测前路由(DEM 90%)
  生产全流程(+mid/真值/指标)    ~215 对/城(南昌 0.966 实证)
  全套实验档(+50m框/三防线/验证) 317-1034 对/城,均值 ~1000
  增强项单价:S5b ≈80对/+3.3pt·城(渲染增强,不进路由参考);REBAL ≈85对/城(几何)
  效率基准:批量 matrix 50对/请求(5907 次承载 2.2 万对);10 QPS 匀速+401/302 退避
```
