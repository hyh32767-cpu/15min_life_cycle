## 研究怎么读

- **先理解策略**：[当前原理与限制](research/README.md)，再到 [experiments](../experiments/README.md) 查对应脚本。
- **看准确性**：[兰州内部河道反例与修复](76-河流内部屏障检查修复.md)、[2公里网格数据完整性](72-两公里范围百米网格全量盘点与重算.md)。
- **看真实耗时**：[重庆新点](77-新点网格与扇形冷启动计时.md)、[杭州和苏州](78-两个新点一公里一网格计时.md)。它们不是5/10/15层加设施的整页耗时。
- **看限流过程**：59—68的记录保留当时账号和发送条件，不作为所有账号的默认权益配置。

离线复算、真实API测量、产品集成、界面检查是不同证据。数据位置、算法版本和比较限制见各报告，不把不同时期的最佳指标拼成当前性能。
