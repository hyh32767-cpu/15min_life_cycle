# 截图视觉基准与组件比例

2026-10-15，依据用户本轮上传的五张原型截图整理。本次只分析截图并记录规范，没有自动访问此前受浏览器工具限制的原型文件，也未修改正式页面样式。

## 截图中的设计关系

1. 第一张：搜索、地点快捷项和模式切换各有稳定容器；主色集中在当前项。地图边界清楚、填色浅，气泡用图标、地点和耗时组成，工具按钮留出独立区域。抽屉标题描述当前地点/任务；时间控件与完成状态相邻。摘要卡以圆环数字和地点信息并排，避免所有内容等权排列。
2. 第二张：设施卡采用两列，第一行是图标、类别、右对齐的百分比，第二行细进度条，第三行数量和简短说明。白底占主体，低覆盖用橙色；只有当前查看项用蓝色描边。卡片不需要每张铺满绿色，也不需要重复多个进度和点数。
3. 第三张：建议卡有单独的浅绿色背景，标题、说明、预览动作顺序明确，视觉上承接当前选中的设施类别。
4. 第四张：建议预览后的地图气泡、面板说明和绿色按钮状态一致，点击结果可直接看见。
5. 第五张：顺路地点卡把名称放在首位，绕行/距离在下一行，一条短标签说明推荐理由；右侧只留一个适量大小的操作。加入状态以绿色反馈。圆环摘要中的额外时长和地点列表形成主次，不使用占满底部的总入口抢走焦点。

## 图标与颜色

- 类别图标使用同一套简洁彩色图标；地点/服务图标可以有颜色，工具按钮统一线性图标，线宽与尺寸统一。不能混用尺寸悬殊的emoji、很小的文本符号和大号方向字符。
- 主蓝负责当前项、地图边界和主要动作；绿色负责完成/已加入及积极状态；橙色负责覆盖短板；浅灰负责背景、轨道和次要信息。
- 主数字和地点名称用深色，辅助描述用灰蓝。白底、浅灰底、单层细边框构成主要层次，阴影仅用于需要浮起的面板和气泡。
- 选中胶囊/设施卡和对应地图对象的颜色一致。未选项有足够对比度，不用低透明度把可点击内容画得像禁用。

## 沿用当前已确认的交互

组件比例借鉴这些截图，入口位置仍按用户最新要求：模式、搜索和统一收藏位于下方抽屉；收藏共用地点/路线；今天安排蓝条、重新开始、地图legend已删除。截图中的顶部整块搜索、预设示例城市等不作为恢复旧入口的依据。

截图中的82分、24小时营业、骑行模式、具体覆盖增益等不是现有真实能力的证明。只借鉴信息排布与状态反馈；正式数值和营业状态继续来自当前真实证据。圆环可以展示现有平均覆盖率/额外耗时，不把参考图分数硬套成新指标。

后续视觉调整先统一基础字号、空间、图标、按钮，再处理摘要卡、设施卡、顺路卡和地图气泡，避免只换颜色或继续整体缩小组件。本轮未执行样式落地，也未新增API调用。
