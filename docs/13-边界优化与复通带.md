## 二、义乌"针状边界"复盘与弦差再平衡(REBAL)

**用户圈出义乌东侧针状内刺(95.6°=486m vs 邻 842/805m,深 350m)**。复盘结论:

1. **地形是真的,渲染是错的**:三条射线的完整距离阶梯独立证实——95.6° 481m=621s →
   491m=1079s,98.4° 481m=603s → 500m=1079s(墙两侧各 4-5 个单调测点),而 1.4° 外
   94.2° 可达 856m:一条 ~80m 宽、380m 深的硬屏障槽(铁路性质),真值格 90°/500m
   T=1079s 旁证。**不是 API 噪声**。
2. **算法缺口**:mid 违规只插了一根 95.6° 射线,两侧弦差 Δ356/319m 却无规则继续
   细分——真凹口被画成一根针。
3. **修复:弦差再平衡规则**——凡 |r_a-r_b|>150m 的弦,中点方位无条件 bisect(tol25),
   迭代至 Δ<150 或弧 <2°。十五城全部执行(+3~20 向/城,共 120 对,早前探针在缓存
   使 bisect 大半免费);义乌槽壁现有 94.2/95.6/98.4/99.8 四向支撑,视觉复核
   "孤针→有宽度凹槽,不再病态"。
4. **指标代价(诚实记录)**:R0 多边形平均 0.903→0.896,最优规则由 R2并(0.930)
   翻为 R1场(0.926)——去针换取几何真实,指标小幅回撤。

## 三、多 15min 点轮廓:复通带表示法(BAND)

**用户指出(遵义蓝框)**:边界在射线上有垂直凹陷——一根射线上 15min 线被穿越多次,
单半径表示无法绘出轮廓。严格扫描(阶梯必须含"超时带夹层")全十五城共 **8 条射线 / 5 个
复通带**:哈 33.7°/45°(东北)、渝 153.4°、沙 157.5°、桂 163.1°、遵 135°(湘江桥廊)。

**表示法升级**:pocket = {bearing, wedge, r, gap:[g0,g1], outer}
- r=主边界;gap=隔离带(江河/围墙);gap 外为复通段,至 outer(第二边界)
- 例:遵义 135° r=598 | 隔离带 606-739m | 复通至 779m(实测二分,±25m)
- 地图新增两层:**玫红 X=每向全部 15min 穿越点**(每城 22-110 个,含主边界外的);
  **青绿楔形=复通带**(隔离带外桥廊可达段)
- 分类规则 R2并+复通带:**十五城平均 IoU 0.933**(全历史最优;R0 多边形 0.903)

**事故与返工记录(诚实)**:①REBAL v1 因 CityRunner 预算按全局 EID 计数,首城耗尽后
其余十四城 bisect 全零探针,写入 **135 条 800m 假半径**——已全数清除,仅义乌(首城)
的重平衡真实有效;②BAND v1 二分方向写反产出垃圾值并覆盖哈尔滨旧口袋——已恢复并用
显式方向函数重写(v2)。两次同根:**截断≠失败必须显式暴露**。REBAL 其余城市的重平衡
重做挂起(估 ~350 对,预算尽后另批)。

## 六、圈内间隔带(2026-08-31,零 API;用户蓝圈追问驱动)

**用户追问**(哈尔滨蓝圈):射线上很多 15min 穿越点,为什么边界没变?
**诊断**:X 标记 = 每向阶梯上**每一次** OK↔X 穿越。蓝圈区 129.38° 的阶梯是
`OK(800-903) → X(903-950) → OK(950-1016) → X`——**圈内间隔带**(屏障楔夹在两段
可达之间),而主多边形取最后穿越点 983m,把整个楔形盖住了;其余 X 是八根加密
射线各自的主穿越点(贴在边界上,本就不该"改变"边界)。
**修复(零 API)**:十五城批量提取 `interior_gaps`(严格语义:X 带夹在两段 OK 之间、
宽 ≥20m),地图新增**深红斜线楔形层**,分类口径在 R2并+复通带基础上**减除**圈内带。
**结果**:十一城共 24 条圈内带(重庆 4/长沙 5(滤零宽)/成都 3/武汉 3/洛阳 3/
桂林 2/遵义 2/B/哈/西/义各 1);十五城 IoU **0.933→0.934**(窄楔对指标贡献小,
价值在表示完整与诚实——圈内"看着可达实际不可达"的位置第一次被画出)。
**教训**:**每次升级表示法,旧证据要回头重读一遍**——阶梯里的非单调段早就在
缓存里,只是上一版表示法没有它们的位置。

## 八、纯几何方法实验：不可靠(2026-09-01,零 API)

**用户提议**:生产环境无缓存场时,能否纯几何(不插射线)解决弦间凹凸?
**测试**:①α=0.3 最小偏向插值 ②二阶差分走廊/墙检测+修正。二十社区对照 50m 场线:

| 方法 | 平均 RMS | 结论 |
|---|--:|---|
| 线性插值(基线)| 112.2m | — |
| α=0.3 偏 min | 116.7m | 14/20 城变差 |
| 二阶检测+修正+α | 122.0m | 更差 |

**根因**:"障碍向内切多于向外凸"在 aggregate 不成立——广州/上海/珠江新城等
凸出型城(桥/广场/规则路网)被系统性压扁(-38~-53m),少数凹口型城(义乌/长沙)改善。
**结论**:线性插值已是不加测量时的最优无偏估计;生产推荐 **|Δr|>120m 弦发 1 个
探针**(~4 对/城,二十社区 81 对)用实测定方向,优于任何几何猜测。
