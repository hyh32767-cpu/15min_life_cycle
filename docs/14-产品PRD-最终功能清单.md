## 1. 产品定位(不变,证据升级)

用户选一个社区中心 → 真实路网 15 分钟等时圈 → 五类设施体检 → 盲区诊断
(缺设施 vs 走不过去)→ 选址处方 → 报告。

**差异化从口号变成实测**:绕行系数、复通带(湘江桥廊)、圈内间隔楔(院内不可达)、
义乌 80m 窄槽等均有逐探针证据链;十六城 IoU 0.934、南昌从零全流程 F1 0.982。

## 2. 最终功能清单

### F1 · 中心点定位 ✅
- 地址 → geocode → 中心(bd09);`geocodes.json` 地址缓存,重跑 0 调用
- 验收:同地址二次解析零 API(docs/12 断言通过)

### F2 · 等时圈引擎(核心)✅
**8 向起步二分(tol50)→ 六规则加密链(证据驱动,候选筛查 0 对):**

| # | 规则 | 触发条件 | 实证 |
|---|---|---|---|
| 1 | 弦规则 | 扇区内实测超时点落入多边形 / θ≥30° | 十六城收敛 k=16~87 |
| 2 | mid 探针 | 弦中点 0.97r 超时 → 插向 | 收敛判据=违规数(F1 会说谎)|
| 3 | ρ 热弦(收窄版)| ρ>max(τ,2.2) 且 Δr<150 且 arc>22.5° | 重庆相关性误差案例 |
| 4 | 弦差再平衡 | \|Δr\|>150m 无条件插 | 义乌"针"→凹槽 |
| 5 | 小角度弦验证 S5b | arc≤22.5°且(Δr>80 或 arc≤11.25°):边中点实测凹/凸 | 南昌 IoU +3.3pt/80 对 |
| 6 | 复通带 | 阶梯含超时带夹层 → pocket={r,gap,outer} | 6 条江河桥廊(遵义蓝圈)|

**三层边界表示**(同时输出):
- 主多边形(射线半径)+ 重建场(全样本 Delaunay+弦约束,50m 分辨率)
  + 复通带楔形 & 圈内间隔楔(实测不可达带)
- 分类口径:**R2并+复通带−圈内带 = 十六城平均 IoU 0.934**

验收:新社区 8 起步全自动收敛、违规清零;边界无针状/无假半径。

### F3 · 多阈值等时线 ✅(缓存重放,0 对)
5/10/15/20 分钟同场套叠(方法不绑定"15 分钟")。验收:任一阈值 ≤1 分钟离线出图。

### F4 · 设施体检 ✅
- **五类 taxonomy**(医疗/教育/购物/药店/养老,关键词表含补词版——养老 0→6 家实证)
- 检索半径 2km、uid 去重、缓存场 Delaunay 插值 + 直线×ρ 兜底
- **加权评分**:医疗 .25/教育 .20/购物 .20/药店 .15/养老 .20(哈尔滨 94.1,与手算一致)
- 盲区两层:8 扇区盲区 + 50m 格网盲区(轻/中/重三档)

### F5 · 障碍诊断 ✅
- 绕行系数 BarrierIndex(逐盲区格)+ 城市系数表(十六城中位 1.29~2.98)
- **结构性障碍定位**:复通带(过河桥廊)/ 圈内间隔楔(院内隔断)/ ρ 热弦走廊
- 措辞边界保留:"疑似路网阻隔"(仅路径 API,不声称有围墙)

### F6 · 选址处方 ✅
- MCLP 贪心最大覆盖(k=1/2/3);**OSM 初筛 → 百度破平 → 处方**
  (养老 3 站百度口径 98.5%;教育旧址 OSM 100%→百度 8.7%,换址 87%)

### F7 · 体检报告 ✅
结构化 md(docs/12 格式):链路账本(本次新增调用数)/评分表/盲区/处方 Before-After。

### F8 · 一键管线 ✅
`python experiments/pipeline.py [--live] [--addr …]`:地址→等时圈→体检→评分→选址→报告;
**缓存模式二跑零调用断言**;预算护栏 + 302 优雅降级(不写假半径)。

### F9 · 成本与配额管理 ✅

## 4. API 设计(pipeline 六步直译)

```
POST /api/analysis {addr|lng,lat}      → {analysisId, status}
GET  /api/analysis/{id}                → isochrone{polygon, field, pockets, inner_gaps}
                                         + health{score, categories} + blindZones[]
                                         + prescription{sites[]} + report_md
GET  /api/analysis/{id}/ledger         → {calls, pairs, cache_hit}   # 账本透明
```
