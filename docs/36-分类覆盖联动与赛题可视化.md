# 分类覆盖联动与赛题可视化

2026-10-13。修正用户指出的养老 0 家、0% 却显示覆盖 100% 和无改善建议的问题。

## 问题与修正

原覆盖详情对五类设施取并集：能步行到达任意一类就算覆盖。新增建议又用这个并集作基线，购物覆盖全部采样点时，养老缺口被掩盖。这个结果不能作为五类服务完整性。

每类现在保留独立覆盖结果、实际有向测时、参评设施及额外候选。首次体检默认选择已完成类别中覆盖率最低的一类；柱状条选择、类别详情、地图采样格和改善建议同步切换。五类加权分独立展示，不再用某类/并集覆盖率作为未知综合分的替代。

养老未检索到设施、但检索已完成时，所选类别明确显示 0/9，改善建议提示没有可评估候选位置并引导手动选点试算，不能据此说没有改善空间。空检索且截断仍为未知，不填 0，不画完整评分雷达面。没有增加覆盖的候选不强行挑满 1/2/3 点。模拟新增只使用当前类别的基线和未覆盖点测值，不混入其他类别，结果不写回真实评分。

当前步行覆盖格使用 500 米格中心采样的评估结果填色，灰色为所选类别未覆盖，不能推断格内每个位置或人口的完整可达性。独立 1 公里菜市场/药店/小学体检仍采用地理半径规则，地图通过显示模式区分，切换类别不会混合两套覆盖结果。

## PDF 原文与可视化

已读取根目录赛题 PDF 两页。第 2 页要求地图准确渲染真实路网计算出的“等时圈”热力图；用户体验评分列举热力图、柱状图、雷达图等形式，没有逐项强制全部图形，也没有单独的“图标”要求。

这里将等时圈热力图理解为步行可达时间的空间展示。现有 5/10/15/20 分钟分别测量、完整边界分层填色保留，并把入口明确改为“显示步行热力图”。这是分层时间范围，不是每个位置都有实测耗时的连续插值热力面；缺测层不填完整面。灰色设施覆盖格是另一个指标图层。

新增五类覆盖雷达图，直接使用各类实际采样覆盖率。0% 落在中心，未知显示“待查明”且不绘制完整面；柱状条保留类别选择。无障碍描述包含五类及对应比例，手机图形和标签完整显示。
