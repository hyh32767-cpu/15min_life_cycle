## 2026-09-02(续)· 地形信号 + 兰州 50m

| 里程碑 | 对数 | 产出 |
|---|--:|---|
| 兰州 50m 网格(±500m, 441/441) | 441 | 场点入缓存 |
| 兰州黄河分析:50m 场线在河段仍锯齿(75-226m 震荡) | 0 | **插值在极端地形无解** |
| 地形三层信号验证(路线折线/路名/POI) | ~10 | 折线偏角>60°+横向偏移>120m=绕行;路名含"中山桥"=桥;POI 搜"桥/河/隧道"可用(独立池) |
| 十城地形信号 vs 50m 场线相关性 | 0 | 哈尔滨信号吻合1/1、重庆2/4;但成都14处仅3吻合、西安0/13——**地形信号只能解释部分偏差** |

**核心发现(兰州黄河)**:
- 射线多边形:V 形尖刺(90°=205m → 95.6°=809m,线性插值跨 600m 悬崖)
- 50m 场线:锯齿震荡(80-110° 内 75-226m 交替)——**插值在河宽 <采样间距时无解**
- 路线折线:偏角 82-90°、横向偏移 127-153m、路名"中山桥"——**唯一可靠的地形信号**
- **结论**:地形表示 = 障碍+桥的显式分层(复通带),不是更密采样;采样密度 ≠ 表示精度
