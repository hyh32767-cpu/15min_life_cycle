# 跳转联动、地图缓存与手机流程优化

收尾日期：2026-10-13。工作源码仍在 `/Users/heyh/projects/15min_life_cycle`，源码目录/Git整理和最终发布包按此前要求最后处理。

## 跳转与状态

- 沿途生活圈进入社区时携带选中的中心及同一个步行时长，提供“返回沿途”。跳转只交接上下文，不自动测圈；需要更新时显式点击时间按钮或计算覆盖。
- 社区时间按钮和覆盖体检共用步行预算。更改中心/预算使旧圈、热力、圈内 POI、评分和新增点坐标失效；在途旧响应不能回写，不把旧图留作新时长的结果。
- 主页面用最多四个实例的 KeepAlive 保留结果、输入草稿和折叠状态，跨页返回不再重建表单、重复调用业务接口。保留的是之前已测结果，不表示每次返回进行了新测量。
- 切页取消未确认选点、关闭弹窗并释放滚动/键盘锁，面板回到顶部；已确认的社区新增点坐标由页面自己保管，不依赖其它页面的临时选点槽。
- `/isochrone` 统一重定向到社区入口；社区未选中心时不再显示旧通勤路线，空档页不混入通勤选店的绕行线。

## 地图缓存范围

全局底图实例保留，SDK 加载沿用单例。各页面在内存中分别保存真实地图中心和缩放级别；同一业务中心返回时恢复上次手动视角，换业务中心则定位到新中心，避免恢复旧地点。覆盖物更新保持比例尺；容器尺寸变化也恢复最近的用户视角。

这轮新增的是页面结果和地图视角复用，不是离线地图下载。硬刷新后页面内存视角会重建；百度底图瓦片、图标及资源仍由浏览器与百度 SDK 缓存管理。本机真实网络面板观察到磁盘缓存命中，未绕过服务端测值 TTL、版本或来源 hash 校验。更新测量仍走原 provider/后端有效缓存及真实请求链。

## 主流程与辅助操作

社区主流程收敛为“选择中心 → 选择步行预算 → 计算覆盖 → 查看分项”。计算按钮前置至中心选择区；无结果时不铺满空评分、诊断和建议卡片，也不显示空指标卡或禁用的分层热力按钮。

自定义步行预算、1 公里基本设施、九格清单和模拟新增设施按需展开。自定义预算始终可用；模拟新增须先有完整基线，名称和位置齐备才允许对比。打印时临时展开折叠内容，结束后恢复用户原状态。通勤的选点、地点库、路径库、设置、更多类别与安排弹窗互斥，减少多组操作同时堆叠。保留蓝紫风格、地图/底部面板和已有功能。
