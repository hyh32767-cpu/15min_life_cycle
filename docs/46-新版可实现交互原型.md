## 页面与操作

沿用原型的全屏底图、白色悬浮搜索、蓝色主色、圆角卡片。桌面左侧悬浮工作台；手机顶部搜索和双模式入口，底部22/49/82dvh三档抽屉，点击或拖动切换。缩放/定位/图层位于地图侧边，跟随抽屉让位。首次页面默认生活圈。

| 流程 | 默认展示 | 按需进入 | 现有能力对应 |
| --- | --- | --- | --- |
| 生活圈 | 地点名称地址、5/10/15/20分钟、覆盖概览、所选服务紧凑卡 | 调整服务、设施详情、未覆盖位置、新增模拟、报告 | community / isochrone / mapRoute |
| 顺路办事 | 路径端点、途经地点、沿途类别和门店行 | 统一地点选择、顺序调整、停留、出发设置、整体安排、行程执行 | commute / plan / execution / routeBand |
| 地点选择 | 搜索、收藏、定位、地图选点 | 确认地图位置、保存地点 | LocationPicker / WaypointPicker / savedPlaces / mapInteraction |
| 复用路径 | 我的地点、我的路径、保存路径 | 用收藏设置端点，路径反向并反转途经顺序 | PlaceLibrary / routePresets |

降低操作复杂度：一个选点器承担生活圈中心、路径端点、途经点和收藏；地图选点只选择并确认位置。设施卡点击只切换类别与地图，不自动规划。设施详情显式“从这里去”才开路线。途经列表默认只展示名称/停留，排序和编辑收进单独面板；起终点不局限于家与公司。出发设置只管出发时间和最多额外步行，整体安排只管多地点的统一计算。
