## 2. SN 签名规格(本次最大工程收获)

官方 FAQ 算法在本环境下**不能直接用**,实测修正:

```text
queryStr = path + "?" + k1=v1&k2=v2...     # GET 按插入序,值为原文
stage1   = quote(queryStr, safe="/:=&?#+!$;'@()*[]")   # ⚠️ 无逗号版!
sn       = md5( quote_plus(stage1 + SK) )
```

- 官方 safe 列表含 `,`;但 direction/reverse 的服务端按 RFC1738 重算,值中的逗号编码为 `%2C` → 用官方列表必挂 211
- 另见 [编码规范](https://lbsyun.baidu.com/faq/api?title=webapi/appendix):保留字符作**字面值**时必须编码
- 实现:`core/baidu_client.py::_signed_params`

## 3. 仪器特性(E2)

| 特性 | 实测 | 对算法的含义 |
| --- | --- | --- |
| **确定性** | σ̂ = 0.00s(6 对 × 3 轮完全一致) | f(o,d)=t 是确定性函数;**二分法可以精确收敛**,停机阈值取 \|Δt\|<1s 即可 |
| **对称性** | f(d,o)−f(o,d):均值 −0.7s,极值 −4s | 近似对称,采样只需"从中心出发"单方向建模 |
| **隐含步速** | 3.5–4.2 km/h,中位 3.9 | 全部落在合理带(3–6),无脏数据 |
| **射线单调性** | 104 点中 **10 个违反**(270°×3、90°×4、45/135/180°各1) | **二分法适用边界实锤**:西向(故宫屏障)与东北向存在非单调区段,纯二分会钉错边界 → 用"粗扫+局部二分"混合策略 |
