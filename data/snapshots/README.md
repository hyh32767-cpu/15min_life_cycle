# 运行数据静态快照

按项目维护者授权，同步时使用SQLite一致性备份生成 `api/cache.db`、`api/derived.db`、`api/ledger.db`，并清除密钥、认证头与签名参数。本机正在使用的 `api/var/` 原文件不改动。研究数据库和历史缓存仍在 `experiments/logs/` 与 `cache/`。

这些是历史响应与计算结果，不保证在使用时仍有效；应用会按源有效期和算法版本校验，不将过期数据冒充实时结果。含有位置和地图服务响应，沿用相应服务条款，不属于原创代码MIT再许可的数据集。

如需在自己的本地环境恢复这三份快照，先停止应用并备份原有运行数据，再复制到 `api/var/` 的对应文件名；不要覆盖正在写入的数据库。干净安装也可以不恢复，应用会自行创建新的运行数据库。

凭据从自己的 `.env` 或服务端环境注入，快照不提供可用密钥。旧Git历史曾包含密钥，当前快照清理不能替代旧密钥轮换。
